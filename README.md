# 📈 FinPulse

## Indian Market Intelligence Dashboard

FinPulse is a full-stack stock market intelligence dashboard built using **React, FastAPI, SQLite, and Yahoo Finance**. It tracks 20 NSE-listed companies, stores historical market data, exposes REST APIs, and visualizes market trends through an interactive dashboard.

---

## 🚀 Live Deployment

**Frontend**
https://fin-pulse-plum.vercel.app/

**Backend API**
https://finpulse-backend-lghv.onrender.com

> **Note:** The backend is hosted on Render's free tier. The first request after a period of inactivity may take 30–60 seconds while the service wakes up.

---

## Features

- Track 20 NSE-listed companies
- SQLite database
- FastAPI REST APIs
- Historical line chart
- Interactive candlestick chart
- Company comparison
- Stock screener
- Market summary dashboard
- Responsive React frontend
